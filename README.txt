SITE DE CONSENTEMENT - CALLO SERVICE

Fonctions :
- Création d'un lien unique pour chaque prospect
- Boutons OUI / NON
- Une seule réponse par lien
- Enregistrement :
  * adresse e-mail
  * réponse
  * date/heure UTC
  * adresse IP
  * navigateur / user-agent
  * referrer
  * identifiant unique de preuve
- Journal admin
- Export CSV

INSTALLATION LOCALE
1. Installer Python 3.
2. Ouvrir un terminal dans ce dossier.
3. Installer Flask :
   pip install flask
4. Lancer :
   python app.py
5. Ouvrir :
   http://127.0.0.1:5000

MISE EN LIGNE
Le site peut être déployé sur Render, Railway, PythonAnywhere ou un VPS.

IMPORTANT
La page /admin n'est pas encore protégée par mot de passe.
Avant une utilisation réelle, ajoutez une authentification admin et une politique
de confidentialité adaptée à votre traitement de données.
